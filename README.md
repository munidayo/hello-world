# Duel Card Studio

写真をアップロードして、デュエマ風のオリジナルカード画像を作れるWebアプリです。Canvas版の即時プレビューに加えて、OpenAI APIキーを設定すると、写真解析からカード名・文明・能力・フレーバー・豪華な全面イラスト風カード画像までAI生成できます。

## できること

- 任意の写真をカードイラスト枠へ合成
- カード名、種族、文明、コスト、パワー、レアリティ、能力文、フレーバーテキストを編集
- 文明ごとのグラデーション枠とキラ風エフェクトを切り替え
- 写真を読み取ってカード設定を自動生成
- ChatGPT/OpenAI画像生成で、全面イラスト寄りの豪華カード画像を生成
- 生成したカードをPNGで保存

## 開発

```bash
npm install
npm run dev
```

OpenAI連携を使う場合は、プロジェクト直下に `.env` を作成してください。

```bash
OPENAI_API_KEY=sk-...
```

ブラウザで写真を選び、「AI生成する」を押すと、以下をまとめて生成します。

- カード名
- 種族
- 文明
- コスト / パワー / レアリティ
- 能力テキスト
- フレーバーテキスト
- 豪華な全面イラスト風カード画像

手元の参考プロンプトがある場合は、アプリ内の「追加演出プロンプト」に貼り付けると、その指示を画像生成に反映します。

## ビルド

npm run build
